# Cqlib Skills

Agent skills for the Cqlib ecosystem. Each skill is self-contained under
`skills/<skill-name>/` and provides a `SKILL.md` entry point with optional
task-specific references, scripts, and assets.

## Available Skills

- [`cqlib-python`](skills/cqlib-python/SKILL.md) — Build, test, debug, and
  migrate applications using the modern Cqlib Python SDK.

Planned skill domains include `cqlib-rust`, `cqlib-c`, `cqlib-tianyan`, and
`cqlib-adapter`. Add each domain only when its instructions and supporting
resources are ready to validate independently.
